# Pakistan Cultural Website

A basic first-semester academic website created using HTML, CSS, and JavaScript.

The project was developed as an early learning project to practice basic webpage structure, styling, navigation, and simple JavaScript functionality while presenting information about different cities and regions of Pakistan.

## Features

- Home page
- About Us page
- Contact Us page
- Information about different cities and regions of Pakistan
- Image-based city sections
- Basic navigation
- "See More" functionality
- Team member section

## Technologies Used

- HTML
- CSS
- JavaScript

## Featured Regions

The website includes content related to:

- Islamabad
- Karachi
- Lahore
- Khyber Pakhtunkhwa
- Balochistan
- Kashmir

## Project Background

This was developed as a group academic project during the first semester of BS Information Technology.

It was one of my early web-development projects and was created primarily for learning basic frontend concepts.

AI-assisted development was used for parts of the implementation.
